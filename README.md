# Customer Churn Prediction System

## Overview
End-to-end ML system predicting customer churn and segmenting customers into risk buckets.

## Tech Stack
- Python
- Scikit-learn
- Pandas
- Logistic Regression
- GitHub

## Workflow
1. Data preprocessing
2. Feature engineering
3. Model training
4. Feature Importance
5. Risk scoring
6. Deployment-ready pipeline

## Output
- Churn probability
- Risk classification (Low / Medium / High)
- Visual Representation of Features Importance
